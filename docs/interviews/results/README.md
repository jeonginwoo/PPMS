# 인터뷰 기록

인터뷰 화면에서 내보낸 `.md` 파일을 여기에 모은다.

## 파일명

```
<날짜>-<담당>-<이름>.md      예: 2026-09-22-영업-홍길동.md
```

내보내기 버튼이 이 이름으로 내려받는다. 브라우저 기본 다운로드 폴더에 떨어지므로
이 폴더로 옮겨 둔다.

## 언제 넣는가

**인터뷰가 끝나는 그 자리에서.** 답변은 브라우저 안(localStorage)에만 있어서,
내보내지 않으면 남지 않는다. 브라우저 데이터를 지우거나 다른 PC에서 열면 보이지 않는다.

- 타이머를 멈추면 내보내기 창이 자동으로 뜬다.
- 내보내지 않은 답변이 있는 채로 창을 닫으려 하면 브라우저가 한 번 물어본다.
